# RYM_VARGANI V1.7.2.9 — Day-wise Summary and Detailed Views

Day-wise Report now offers two selectable views:

## Summary
Compact list:
- Donor Name
- Mode of Payment
- Amount

Designed for fast checking on mobile with minimal column spacing.

## Detailed View
Card-wise record with:
- Donor Name
- Receipt Number
- Mode of Payment
- Amount
- Receipt Date
- Payment Received Date
- Status

The selected Date and Payment Mode filter applies to both views.

No new Supabase migration is required beyond `upgrade-v1.7.2.8.sql`.

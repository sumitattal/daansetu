# RYM_VARGANI V1.6.3

## Payment Pending visibility
When a receipt has been issued with **Receipt Given - Payment Pending**:
- Donors view shows a yellow **Payment Pending** badge and Receipt Number.
- Pending view shows the same yellow status and Receipt Number.
- Route Collection (desktop and mobile) shows the same status; the mobile route card remains compact and only adds this warning when applicable.
- Once the pending receipt is settled to Cash/UPI/Bank/Cheque, the special yellow status automatically disappears and the normal donor status is shown.

No Supabase SQL migration is required for this release.

# RYM_VARGANI V1.7.4.5

## Dashboard donor search amount display

When a donor is selected from Dashboard > Search Donor:

- Donation Collected -> shows **Current Donation** and the amount collected this year.
- Pending -> shows **Last Year Donation** and last year's donation amount.
- Receipt Given - Payment Pending remains a pending state and therefore continues to show Last Year Donation until payment is marked received.

No Supabase SQL migration is required.
